Web2Exe Studio

Web2Exe Studio, statik web projelerini (HTML/CSS/JS), web klasörlerini veya ZIP arşivlerini tek tuşla taşınabilir Windows uygulamalarına (.exe) dönüştüren bir yerel stüdyo uygulamasıdır. Bu sayfada programın nasıl çalıştığı, hangi dosyaları desteklediği, sınırlamalar, güvenlik önerileri ve indirme bağlantısı eksiksiz olarak yer almaktadır.

Nasıl çalışır (kullanıcı akışı)

  1. Web2Exe Studio uygulamasını çalıştırın (indirilen klasörü açın).
  2. Uygulama penceresine HTML, web proje klasörü veya .zip arşivini sürükleyip bırakın veya "Dosya/Klasör Seç" butonunu kullanın.
  3. Program iç analiz motoru dosyaları tarar, ana giriş sayfasını (index.html) ve varlıkları tespit eder.
  4. Özelleştirme seçeneklerinden uygulama adı, pencere boyutu, menü gizleme ve çıktı klasörünü seçin.
  5. "WINDOWS UYGULAMASINA DÖNÜŞTÜR (.EXE)" butonuna basın; canlı derleme konsolunda ilerleme görünür.
  6. Derleme tamamlandığında tek dosya (portable .exe) seçtiğiniz çıktı klasörüne kopyalanır.

Detaylı teknik akış

  • Doğrulama: Seçilen öğe ZIP / dosya / klasör olarak analiz edilir. HTML sayfası veya index.html aranır.
  • İçerik hazırlığı: Geçici çalışma dizini oluşturulur; kaynaklar oraya kopyalanır (node_modules ve .git gibi büyük/donanım klasörleri opsiyonel olarak hariç bırakılabilir).
  • Self-healing: Eksik main.js veya package.json varsa otomatik üretilir (pencere ayarları, entry HTML ayarlanır).
  • Build: Derleme, Electron Builder aracılığıyla ayrı bir Node alt sürecinde çalıştırılır; hedef: Windows portable (.exe).
  • Çıktı: Üretilen .exe çıktı klasörüne kopyalanır ve kullanıcıya açma/kopyalama seçenekleri sunulur.

Hangi dosyalar desteklenir?

Program statik web içeriğini paketler. Doğrudan desteklenenler:

  • .html / .htm — tek sayfa veya ana sayfa
  • Web proje klasörleri (index.html, CSS, JS, resimler)
  • .zip — içinde HTML/varlıklar barındıran ZIP arşivleri (otomatik açılır)

Desteklenmeyen veya sınırlı destek:

  • Sunucu taraflı / dinamik backend (PHP, Node server, veritabanı) — bu tür fonksiyonlar paketlenen uygulamada çalışmaz; önce statik bir kopya oluşturulmalı veya uygulama remote API'lere bağlanacak şekilde ayarlanmalıdır.
  • Büyük multimedya (video/stream) — paket boyutuna dikkat edin.
  • Çalıştırılabilir binary'ler (.exe, .dll) ZIP içinde bulunursa üretim sırasında engellenebilir veya antivirüs uyarısına neden olabilir.

Güvenlik & izinler

  • Başkalarının sitelerini paketlemeden önce yasal izin alın. Telif hakkı ve kullanım koşullarına dikkat edin.
  • ZIP içeriklerini paketlemeden önce kontrol edin — yürütülebilir dosyalar (exe, bat, ps1) içermemelidir.
  • Derleme makinesinde Node.js ve gerekli araçlar kurulu olmalıdır; son kullanıcıların exe çalıştırması için Node gerekmez.
  • Yüklediğiniz .exe unsigned ise Windows SmartScreen veya antivirüs uyarıları çıkabilir; büyük ölçekte dağıtım için kod imzalama önerilir.

Nasıl kullanılır? (adım adım - kullanıcı)

  1. Butona tıklayıp ZIP paketini indirin veya tüm klasör içeriğini indirin.
  2. İndirdiğiniz arşivi sağ tıklayıp "Tümünü ayıkla" veya benzeri ile açın.
    ÖNEMLİ: Eğer klasör içinde node_modules yoksa, bazı sistemlerde npm paketleri eksik olabilir. Ancak bu paket, çalıştırılabilir uygulama oluşturmak için geliştiricinin ortamında Node bağımlılıkları gerektirir. Son kullanıcı sadece hazır .exe'yi kullanır.
  3. Çalıştırmak için klasörü açın, start.bat dosyasına çift tıklayın. Açılan CMD penceresinde derleme/başlatma logları görünür. Program açıldıktan sonra CMD penceresini kapatmayın — programın çalışması için gereklidir.

Hata alırsanız / sık karşılaşılan sorunlar

  • Derleme başarısız: Bilgisayarda Node.js ve yeterli disk alanı olduğundan emin olun.
  • SmartScreen uyarısı: .exe unsigned olduğu için Windows uyarabilir — onaylayın veya imzalanmış bir sürüm isteyin.
  • Eksik dosyalar: ZIP'i açın ve index.html varlık yollarının doğru olduğundan emin olun.

Geliştiriciler için not

Eğer siz build yapan geliştiriciyseniz, EXE üretmek için şu gereksinimler gerekir:

  • Windows ortamı (veya CI runner Windows hedefi)
  • Node.js (LTS önerilir)
  • npm install (electron, electron-builder, adm-zip, fs-extra vb.)
  • Derleme için yeterli disk alanı ve internet bağlantısı
Örnek adımlar:
git clone 
cd repo
npm install
npm run build (veya start.bat ile çalıştır ve UI üzerinden paketle)

Test etmeden önce: lütfen ZIP'i indirip yerel olarak açın ve start.bat ile başlatmayı deneyin. Herhangi bir sorun çıkarsa bana bildir.
