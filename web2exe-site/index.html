Web2Exe Studio

Bu sayfa Web2Exe Studio uygulamasının detaylı tanımını ve indirme bağlantısını içerir. Web2Exe Studio, statik web sayfalarını, web proje klasörlerini veya ZIP arşivlerini tek tıkla Windows taşınabilir (.exe) uygulamasına dönüştürmek için tasarlanmış bir araçtır.

Detaylı Açıklama

Özellikler: sürükle-bırak desteği, ZIP açma, otomatik eksik dosya üretimi (package.json/main.js), pencere boyutu ayarları, portable EXE üretimi (electron-builder). Derleme sırasında builder süreci Node.js gerektirir; kullanıcılar sadece üretilmiş .exe'yi çalıştırır.

Programı indirmek için:
Download for Windows
Dikkat: Programı çalıştırmak için Web-to-EXE-Studio klasörüne çift tıklayın, ardından start.bat dosyasına çift tıklayın. Açılan CMD penceresinde biraz bekleyin; program açıldıktan sonra CMD penceresini kapatmayın — programın çalışması için gereklidir.

Test için

Önce bu sayfayı yerel olarak açıp (çift tıklama ile) indirme düğmesini test et. ZIP, node_modules hariç kaynak dosyalarını içerir.
